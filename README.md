# keelbox Homebrew tap

```sh
brew install keelbox/tap/keelbox
```

Installs [keelbox](https://keelbox.dev) on macOS or Linux, arm64 or amd64: the release binary, at the SHA-256 listed in that release's signed `SHA256SUMS`, and (from v0.1.0-rc.3) completion for bash, zsh and fish. `brew upgrade keelbox` updates it; `keelbox self-update` leaves a Homebrew install to Homebrew.

`Formula/keelbox.rb` is written by keelbox's release tooling on every release, so changes made here are overwritten. Without Homebrew: <https://get.keelbox.dev>.
